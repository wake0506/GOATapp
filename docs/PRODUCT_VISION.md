# GOAT Product Vision

GOAT helps users record food, training, body weight, and hydration with as little friction as possible, then turns those records into useful personal feedback.

The first principle is reliable capture: local data must remain available when the network is unavailable, and a failed cloud request must not erase a user's record. The second principle is clear review: history and statistics should use one date meaning across the app. The third principle is progressive assistance: AI may parse or suggest data, but the user reviews and confirms anything that becomes a nutrition record.

Phase 1 focuses on startup stability, account-safe storage, and a voice diet entry flow that is editable and reviewable before saving.
