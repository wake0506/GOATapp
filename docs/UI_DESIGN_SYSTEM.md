# GOAT UI Design System

## Tokens

- Primary: `#008C8C` Mars Green.
- Page background: `#F4F5F7`.
- Surface: white.
- Text: black with restrained opacity for secondary content.
- Cards: white, rounded corners, light shadow, generous whitespace.

## Interaction

- Keep the current clean, restrained, high-end visual language.
- Use one clear primary action per surface.
- Voice entry uses a white bottom sheet with a large top radius, a `#F4F5F7` editable text area, and Mars Green primary actions.
- Listening feedback is low-saturation green with restrained red only for errors or unavailable states.
- Avoid gradients, new dominant colors, heavy animation, and large layout changes.
